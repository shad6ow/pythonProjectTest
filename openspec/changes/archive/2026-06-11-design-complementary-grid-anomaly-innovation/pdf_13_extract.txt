 I 
摘要 
随着科学技术的不断发展以及大数据时代的到来，如何高效处理数据以获得有效信息是
受到广泛关注的课题之一。近些年，作为人工智能子集的机器学习技术常用于完成 数据分析
任务， 如： 回归问题、聚类分析、 异常检测、 关联规则挖掘、 预测建模等。 本文以机器学习中
的聚类算法为研究课题，深入研究了自组织映射模型(Self-Organizing Map, SOM) ，从该模型
的单个获胜神经元机制以及不同类训练数据对模型权重矩阵更新会产生不同影响这两个角度
进行改进，进一步提升聚类算法的性能。 
SOM 神经网络常用于聚类分析、 数据可视化和异常检测等领域， 其易受初始权重矩阵的
影响且单个获胜神经元机制对输入数据敏感。针对以上问题，本文提出一种基于虚拟获胜神
经元的改进 SOM 模型 (virtual-winner SOM, vwSOM) 。首 先 采 用 主 成 分 分 析 法(principal 
component analysis, PCA)初始权重矩阵， 使得初始权重能够更好地捕捉数据的主要特征， 从而
提高聚类效果；随后，当新的输入样本数据映射到输出层后，在权重矩阵中选取相似度较高
的多个神经元节点，计算得到虚拟获胜神经元，并以此更新权重矩阵，在尽量小的误差范围
内全面表征输入数据的特征， 提高算法的鲁棒性。 利用vwSOM 对鸢尾花数据集 （Iris） 、 葡萄
酒数据集(Wine)进行聚类分析， 实验结果表明， 本文算法可以显著提高聚类准确度， 具有更好
的稳定性。 
在 SOM 的训练过程中， 不同类数据对权重矩阵的更新产生不同作用， 某一类数据对权重
矩阵的更新会对其它类获胜神经元特征向量产生偏离其数据特征的影响，从而降低算法聚类
精度。为解决上述问题，本文提出了一种改进的基于置信度 SOM 模型(improved confidence -
based SOM model, icSOM)。样本数据先由 k-means 算法初步分类，为模型训练提供更多的数
据信息； 将预分类后的数据分别训练相互独立的SOM 模型， 以消除不同类之间的影响； 在传
统 SOM 模型基础上提出置信度矩阵概念，通过综合判断获胜神经元的置信度及其与输入数
据间的欧氏距离最终得到置信神经元，根据置信神经元所属类别给数据分配聚类标签。 将
icSOM 应用于 Iris 及 Wine 数据集的聚类分析，通过观察实验结果可知， 本文算法可以更好的
处理样本数据，取得了较好的聚类效果，且算法复杂度可以满足实时数据处理的需求。

第二章 聚类理论知识及 SOM 模型原理 
聚类是无监督学习中的重要一类算法，与分类算法不同的是，聚类可以在缺少数据标签
的情况下， 不关注单个样本的具体特征， 而仅仅是依据各数据间的关系以及规定的特征标准，
将数据集划分为不同的聚类簇。聚类的目的是将相似度高的数据聚为一簇，使簇内距离尽可
能小；相似度低的数据尽量远离，使簇间距离尽可能大。聚类算法根据所采用的方法不同 可
以分为多个类别，本文重点研究的 SOM 算法即属于基于模型的聚类算法。SOM 模型是一种
人工神经网络聚类模型，输出层节点按照与输入样本数据距离远近具有一定的关联，实现了
学习数据本身的特征并且学习数据之间的拓扑关系。SOM 模型在处理缺失标签的数据时具有
良好的普适性；可以将高维输入数据映射到低维输出层中，将聚类结果可视化；另外，由于
其计算复杂度低，可以满足数据实时处理的需求。因此，SOM 模型有很高的研究意义及应用
价值。 
本章首先阐述了数据聚类的原理及过程；介绍了聚类算法的分类，包括各类聚类算法的
基本原理以及其在处理数据时的优势和劣势；引入内部评价指标和外部评价指标 并简介各指
标的计算过程，这些指标将用于后续在实验部分所进行的算法性能衡量。接着，本章着重介
绍了 SOM 模型的训练过程及数据测试过程，通过公式推导和算法流程图等方式详细解释了
SOM 算法原理，为之后的算法优化环节打好技术基础。 
 聚类原理概述 
聚类分析[45][46]是数据挖掘中很重要的一项技术手段。在没有数据标签等先验知识时，可
以利用聚类算法将数据按照规定的特征进行聚类。聚类顾名思义可以理解为 “物以类聚”，是
指可以将数据集根据特定的标准划分为不同的类别或者簇。由于聚类分析不需要将数据与其
具体标签或特征一一匹配，所以计算开销小、运算速度快，适用于实时数 据分析处理，因此
聚类算法具有很深的研究意义及实际应用价值。本小节将从聚类的定义、特点、过程、分类
等方面介绍聚类原理。 
2.1.1 聚类定义及特点 
聚类是指依照规定的标准，如数据间的距离、数据分布密度等，将数据集内特征相似的
数据划分为同一类或同一个聚类簇[47]； 簇中心即为聚类中心， 是该簇中所有样本数据的均值，

每个数据的具体特征指标或标签内容，而仅仅只是关心数据间的关系，即，只将特征相似的
数据聚合到一起[48]。因此，聚类完成后，并不能准确知道每一簇所对应的具体类别。聚类的
目的是使同一类的数据尽量聚集在一起，而不同类的数据尽量远离 。同类数据间的相似度越
高（即簇内间距越小），同时，不同类数据间的相似度越低（即簇间间距越大），聚类效果就
越好。  
2.1.2 聚类过程 
聚类过程示意图如图 2.1 所示，一般包括以下步骤： 
（1）做好数据准备，如归一化、正则化以及降维等。数据集的特征值间有不同范围时，
对数据归一化可以使得特征具有相同的度量尺度，有利于提高算法准确性；对数据正则化处
理，可以防止过拟合，控制算法复杂度，提高算法泛化能力 ；降维可以简化数据特征，去除
冗余及重复的特征部分，留下更简洁更具有代表性的特征值，在尽量不损失数据内容的条件
下减少数据体量。 
（2）选择可以表示数据的特征，从数据原有的全部特征值里选择最能表达数据特点的有
效特征，并将其用向量表示，称为特征向量，用于后续的聚类分析。 
（3）在已有的特征向量集合基础上进行相应的转化处理， 形成新的可以更突出表征数据
特征的特征向量子集。 
（4）根据已选择的特征向量子集， 通过函数模型计算数据间的距离远近或密度稀疏程度，
将数据进行聚类分组。 
（5） 得到聚类结果后， 利用如外部评价指标、 内部评价指标等性能指标和聚类散点图等
评估聚类效果。

 聚类效果评价指标 
聚类效果评价指标可以用来表征算法聚类效果，是衡量聚类结果质量的标准。不同的评
价指标代表算法不同方面的性能，因此，想要全面准确的验证算法实验结果就需要选取合适
的评价指标，它们通常分为内部评价指标和外部评价指标。内部指标适用于评价如聚类等无
监督学习算法性能，它不需要借助数据真实标签，而仅通过聚类分析的数据本身特点就可对
算法作出评价。外部指标则需要利用数据真实标签和聚类结果的标签进行比较，进而评价算
法运算结果。本文所提出的各算法均为无监督学习算法，可以使用内部评价指标；且进行仿
真实验分析所选取的各数据集，其数据真实标签可以获得，故而在输入测试数据过程中，通
过引入数据真实标签可用于后续的算法性能评价环节，实现了对聚类结果的更多角度全方面
的评价、进而更准确的衡量算法性能。

 SOM 模型 
作为无监督学习中的经典聚类模型，SOM[66-69]可用于实现降维、数据可视化、聚类、分
类、 特征抽取等目的。 通过训练SOM 神经网络， 使输入数据映射到输出层节点上， 而输出层
节点按照距离远近具有一定的关联，实现了学习数据本身的特征并且学习数据之间的拓扑关
系。在现实情况中，难以获取大量被标记的数据用于模型训练，而 SOM 模型属于无监督学
习， 在处理缺失标签的数据时具有良好的普适性；SOM 模型可以将高维输入数据映射到低维
输出层中， 将聚类结果可视化； 另外， 由于其计算复杂度低， 可以满足数据实时处理的需求。
因此，SOM 模型有很高的研究意义及应用价值。

第三章  基于虚拟获胜神经元的改进 SOM 模型 
第二章简要概述了聚类的概念， 并重点介绍了基于模型的经典聚类算法——SOM 原理及
其算法流程。但由于传统 SOM 模型存在一定的改进空间， 如：单个获胜神经元的变化会导致
算法对于输入数据的敏感性较高，容易受到噪声干扰等。因此，本章提出一种基于虚拟获胜
神经元的改进 SOM 模型(virtual-winner SOM, vwSOM) 。首先采用 PCA 算法初始权重矩阵，
使得初始权重能够更好地捕捉数据的主要特征，从而提高聚类效果；随 后，当新的输入样本
数据映射到输出层后，在权重矩阵中选取相似度较高的多个神经元节点，计算得到虚拟获胜
神经元，并以此更新权重矩阵，在尽量小的误差范围内全面表征输入数据的特征，提高算法
的鲁棒性。利用 vwSOM 对鸢尾花数据集（Iris） 、葡萄酒数据集(Wine)进行聚类分析，实验结
果表明，该算法可以灵活处理多种分布类型的数据并全面表征数据特征，降低初始权重矩阵
对模型训练的影响程度；因此，可以显著提高聚类准确度，具有更好的稳定性。 
 vwSOM 模型 
传统 SOM 算法易于实现且运算复杂度低， 但其对数据分布要求严格， 在实际异常数据检
测的应用场景中，对于不符合欧氏距离或线性关系的数据分布，算法可能无法产生良好的聚
类结果；使用单个获胜神经元训练模型，不利于从多角度解释输入数据，不能全面表示数据
各方面的特征；单个获胜神经元的变化会导致算法对于输入数据的敏感性较高，容易受到输
入数据的噪声干扰；随机初始化权重矩阵容易使 SOM 网络收敛速度变慢且探索参数空间时
会陷入局部最优解。因此，针对 SOM 模型训练效果易受初始权重矩阵的影响且单个获胜神经
元机制对输入数据敏感等问题，本章提出 vwSOM 模型以提升算法性能，经仿真实验结果分
析，可以看出 vwSOM 算法具有良好的稳定性，可以实现更好的聚类效果。

3.1.3 vwSOM 算法流程 
将 PCA 算法与虚拟获胜神经元思想相结合，作用于传统 SOM 模型，形成 vwSOM 模型

历后，权重矩阵完成更新； 
（5）多次迭代训练模型，使权重矩阵无限接近样本数据的特征。

1.2.2 SOM 模型 
SOM 是无监督学习中的经典聚类算法， 近年来被广泛应用于各个领域， 如： 数据可视化、

障状态的输入。 通过两步异常检测，提高了间歇性故障诊断的准确性， 但对无监督 SOM 模型
进行投票标记，增加算法复杂度，且引入了对数据标签判断的误差。G. Zhou[36]等人提出了一
种基于 SOM 网络的遥感影像分类算法，将像素转化为“量子像素”，并提出用 PE 系数表征量
子像素间的关系， 建立SOM 模型对量子像素间的关联性进行分析， 以实现图片分类； 该算法
有效改善了传统 SOM 模型因只考虑神经元之间的欧氏距离而不能真实反映遥感影像中像素
的类关系的问题；但该算法的聚类效果十分依赖初始数据，不同的遥感影像 数据使得模型的
最优参数难以确定，影响分类效果。 S. Li [37]等人提出了一种自监督的自组织聚类网络 (self-
supervised self-organizing clustering network, OCNet) ，该网络将特征提取和特征聚类过程联合
学习，以自组织层的权重作为聚类中心，利用自组织层的输出作为特征与聚类中心之间的相
似度，级联多层自组织层以实现在不同特征维度下的多个聚类空间的特征聚类；该算法解决
了传统聚类中由于特征提取和聚类过程相互独立而导致的特征提取时没有考虑如何促进聚类
的问题；但该算法必须设定超参数以限制聚类簇的大小，否则会产生大型聚类；且该算法要

第二章 聚类理论知识及 SOM 模型原理 
聚类是无监督学习中的重要一类算法，与分类算法不同的是，聚类可以在缺少数据标签
的情况下， 不关注单个样本的具体特征， 而仅仅是依据各数据间的关系以及规定的特征标准，
将数据集划分为不同的聚类簇。聚类的目的是将相似度高的数据聚为一簇，使簇内距离尽可
能小；相似度低的数据尽量远离，使簇间距离尽可能大。聚类算法根据所采用的方法不同 可
以分为多个类别，本文重点研究的 SOM 算法即属于基于模型的聚类算法。SOM 模型是一种
人工神经网络聚类模型，输出层节点按照与输入样本数据距离远近具有一定的关联，实现了
学习数据本身的特征并且学习数据之间的拓扑关系。SOM 模型在处理缺失标签的数据时具有
良好的普适性；可以将高维输入数据映射到低维输出层中，将聚类结果可视化；另外，由于
其计算复杂度低，可以满足数据实时处理的需求。因此，SOM 模型有很高的研究意义及应用
价值。 
本章首先阐述了数据聚类的原理及过程；介绍了聚类算法的分类，包括各类聚类算法的
基本原理以及其在处理数据时的优势和劣势；引入内部评价指标和外部评价指标 并简介各指
标的计算过程，这些指标将用于后续在实验部分所进行的算法性能衡量。接着，本章着重介
绍了 SOM 模型的训练过程及数据测试过程，通过公式推导和算法流程图等方式详细解释了
SOM 算法原理，为之后的算法优化环节打好技术基础。 
 聚类原理概述 
聚类分析[45][46]是数据挖掘中很重要的一项技术手段。在没有数据标签等先验知识时，可
以利用聚类算法将数据按照规定的特征进行聚类。聚类顾名思义可以理解为 “物以类聚”，是
指可以将数据集根据特定的标准划分为不同的类别或者簇。由于聚类分析不需要将数据与其
具体标签或特征一一匹配，所以计算开销小、运算速度快，适用于实时数 据分析处理，因此
聚类算法具有很深的研究意义及实际应用价值。本小节将从聚类的定义、特点、过程、分类
等方面介绍聚类原理。 
2.1.1 聚类定义及特点 
聚类是指依照规定的标准，如数据间的距离、数据分布密度等，将数据集内特征相似的
